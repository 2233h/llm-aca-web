4 类题干模板（覆盖约 90% 题目）

A 定义型 — “X refers to / is best described as …”

锚定 X，回忆中文概念，扫选项找同义改写。陷阱：放"近邻概念"（RAG 题配 fine-tuning 描述）。

B 场选型 — “…wants to … Which service should it use?”

抓 wants to 后的动作+限定词：without training / quickly → RAG、prompting、Model Studio 托管；own infrastructure / control → 开源自部署、PAI；image → 扩散模型。

C 区分型 — “Which distinguishes A from B?”

找"A 有而 B 没有"。主角是 distinguish 后面的 A。

D 列举型 — “Select two / three”（多选主力）

❗先数清要选几个；漏选错选都 0 分，宁稳勿贪。

选项对错信号词（本卷无判断题，但单选/多选的选项判定同理）

信号词倾向例
always / never / only / all / must / completely大概率 False“LLMs always produce accurate answers.” ✗
may / can / often / typically / one of / help to大概率 True“RAG can reduce hallucination.” ✓
概念张冠李戴（ANI↔AGI、pre-training↔fine-tuning）False官方样题风格

注意：绝对词要连内容一起判断——“CV, speech and NLP are all application areas of AI” 里的 all 是成立的。

长难句三步砍句法

1️⃣ 砍从句/分词短语（which…, that…, based on…, designed for…）→ 2️⃣ 找主谓宾：谁+做/是+什么 → 3️⃣ 剩下全是场景包装。

例：A Generative AI Engineer is responsible for understanding GenAI concepts and Alibaba Cloud technologies that can be used to deploy such applications.
主干 = Engineer 懂 ①GenAI 概念 ②能部署它的阿里云技术。

考场时间策略（LLM-ACA 真卷面：60′ / 50题 ≈ 1.2′/题）

  • 卷面：35 单选 + 15 多选，无判断题；及格 80 = 全卷最多错 10 题
  • 做题序：单选扫荡（1.5′/题）→ 标记难题二轮回捞 → 15 道多选压轴
  • 没把握的用 flag 标记跳过，别死磕；单题卡壳 >2 分钟立刻走
  • ❗题干里的 NOT / except 心里圈出来
  • 读不懂题干就读选项：AGI/ASI/ANI 并列出现 → 考的就是能力分级
